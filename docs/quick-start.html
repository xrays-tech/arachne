    Quick Start

    一分钟跑起来

    把 Arachne 作为库嵌进你的 Rust 程序：加一行依赖，用 arachne::server 的 facade 就能得到可线性化的写入与读取。 本节与你自己的 Cargo.toml 同步推进。

    1. 添加依赖

    默认开启 transport-tonic 特性，会拉取 tonic 传输；不想要任何网络依赖时， 用 default-features = false 得到一个零外部 crate （可离线构建）的精简核心。

    Cargo.toml
    [dependencies]
arachne = { path = "…/arachne" }            # default: pulls tonic transport
# or a transport-free build:
# arachne = { path = "…/arachne", default-features = false }

    一个进程内单节点时，arachne::server 提供最小 facade —— 不需要 tokio runtime 轮询，不需要任何 Runtime / Handle 装配。facade 自己持有独立线程的 runtime。

    2. 最小程序：new → 等选主 → 读写 → shutdown

    下面是一个完整可运行的最小程序（源自 arachne/examples/facade.rs，注释稍作精简，签名与调用与原例一致）：

    rust
    use std::time::{Duration, Instant};
use arachne::server::{Arachne, ArachneError, WalConfig};

fn main() {
    let dir = std::env::temp_dir().join(format!(
        "arachne-facade-example-{}",
        std::process::id()
    ));
    std::fs::create_dir_all(&dir).expect("failed to create temp dir");

    let output = tokio::runtime::Builder::new_current_thread()
        .enable_time()
        .build()
        .expect("failed to build tokio runtime")
        .block_on(async {
            // (1) One node per process — the facade keeps a single global node.
            Arachne::new(1, &dir, WalConfig::default())?;

            // (2) Wait until the node has elected itself leader. Pre-election
            //     reads fail fast (fast non-leader redirect); once leader the
            //     same read resolves to `None` (key not yet set).
            let deadline = Instant::now() + Duration::from_secs(5);
            loop {
                match Arachne::get(b"hello").await {
                    Ok(v) => {
                        assert!(v.is_none(), "unexpected value before write");
                        break;
                    }
                    Err(ArachneError::NotLeader { .. })
                    | Err(ArachneError::QuorumUnavailable) => {
                        if Instant::now() >= deadline {
                            panic!("node never became ready within 5s");
                        }
                        tokio::time::sleep(Duration::from_millis(10)).await;
                    }
                    Err(e) => panic!("unexpected read error: {e}"),
                }
            }

            // (3) A linearizable write, then a linearizable + local read.
            Arachne::set(b"hello", b"world").await?;
            let value = Arachne::get(b"hello").await?;
            assert_eq!(value, Some(b"world".to_vec()));
            let stale = Arachne::get_stale(b"hello").await?;
            assert_eq!(stale, Some(b"world".to_vec()));

            // (4) Delete and confirm absence.
            Arachne::delete(b"hello").await?;
            assert_eq!(Arachne::get(b"hello").await, Ok(None));

            // (5) Shut down: frees the static slot and releases the WAL lock.
            Arachne::shutdown()?;
            Ok(())
        });

    match output {
        Ok(()) => println!("facade lifecycle complete"),
        Err(e) => eprintln!("example failed: {e}"),
    }
    let _ = std::fs::remove_dir_all(&dir);
}
    i

    单实例、单节点是默认：第二次 Arachne::new 返回 AlreadyInitialized；new 之前（或 shutdown 之后）的静态读取返回 NotInitialized。多节点集群或成员管理请改用 Runtime / Handle（见 Tutorial）。

    3. 运行示例

    仓库自带上面这个完整示例，直接运行：

    console
    $ cargo run --example facade
get(b"hello")          -> Some(b"world")
get_stale(b"hello")    -> Some(b"world")
get(b"hello") after del -> None
facade lifecycle complete

    示例源码在 arachne/examples/facade.rs；想要更底层的裸装配， 看 arachne/examples/single_node.rs（Tutorial 有讲解）。

    HTTP 端点：axum 包裹示例

    想让嵌入方只需一个 #[tokio::main] 和 curl？仓库自带 arachne/examples/axum_http.rs：它用 axum 把 facade 的 set/get/get_stale/delete 包成 PUT /kv/<key>/<value>、GET /kv/<key>、 GET /kv/<key>?stale=1、DELETE /kv/<key> 与 GET /readyz。axum 仅在 dev 依赖，不进入生产依赖。

    console
    $ cargo run --example axum_http
# 打印: arachne HTTP server (facade) listening on 127.0.0.1:XXXXX
# 另开一个终端（把 XXXXX 换成上面打印的端口）:
$ curl -X PUT   http://127.0.0.1:XXXXX/kv/hello/world    # -> ok
$ curl       http://127.0.0.1:XXXXX/kv/hello               # -> world
$ curl 'http://127.0.0.1:XXXXX/kv/hello?stale=1'           # -> world
$ curl -X DELETE http://127.0.0.1:XXXXX/kv/hello           # -> ok
$ curl       http://127.0.0.1:XXXXX/readyz                  # -> ready

    4. 可选：构建并运行参考节点

    不想写任何胶水代码？工作区带了 arachne-node 二进制：它把库与 tonic 传输、 Hyper HTTP/1.1 服务器接在一起，是可运行的真实集群节点，也是嵌入 Arachne 的工作示例。

    console
    $ cargo build --release -p arachne-node
$ arachne-node --config path/to/node.toml

    配置是一个 TOML 文件（字段与 docker/bench/configs/n1.toml 一致）：

    node.toml
    cluster_id = "arachne-bench"
node_id = "n1"
listen = "172.30.0.11:7001"        # raft peer port
data_dir = "/data"
http_listen = "0.0.0.0:8001"        # HTTP client port
initial_cluster = [
  "n1=172.30.0.11:7001",
  "n2=172.30.0.12:7002",
  "n3=172.30.0.13:7003",
]
profile = "lan"                     # "lan" or "wan"
    !

    节点在 initial_cluster 里的自身条目必须等于 listen；配置 schema 目前只接受 IP 字面量。单机体验可以用本机地址写一份 initial_cluster = ["n1=127.0.0.1:7001", …] 的配置。

    curl 接口速览

    节点起来后，KV 读写与运维接口都是纯 HTTP（详见 API Reference 的接口表）：

    console
    $ curl -X PUT 'http://127.0.0.1:8001/kv/hello/world'   # -> ok        (线性写)
$ curl 'http://127.0.0.1:8001/kv/hello'                # -> world     (ReadIndex 线性读)
$ curl 'http://127.0.0.1:8001/kv/hello?stale=1'        # -> world     (本地读)
$ curl -X DELETE 'http://127.0.0.1:8001/kv/hello'      # -> ok        (线性删)
$ curl 'http://127.0.0.1:8001/readyz'                  # -> ready
$ curl 'http://127.0.0.1:8001/metrics'                 # Prometheus 文本格式
    i

    多进程部署下，非 leader 节点的 KV 写/读会返回 409 Conflict，body 带 leader 提示（如 not leader; leader=n1 addr=172.30.0.11:7001）； 503 表示当前无法服务（仲裁不可用 / 超时 / 忙），请求不会挂起。
