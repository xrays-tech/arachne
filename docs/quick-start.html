    Quick Start

    一分钟跑起来

    把 Arachne 作为库嵌进你的 Rust 程序：加一行依赖，用 arachne::server 的 facade 就能得到可线性化的写入与读取。 本节与你自己的 Cargo.toml 同步推进。

    1. 添加依赖

    默认开启 transport-tonic 特性，会拉取 tonic 传输；不想要任何网络依赖时， 用 default-features = false 得到一个零外部 crate （可离线构建）的精简核心。

    Cargo.toml
    [dependencies]
arachne = { path = "…/arachne" }            # default: pulls tonic transport
# or a transport-free build:
# arachne = { path = "…/arachne", default-features = false }

    一个进程内单节点时，arachne::server 提供最小 facade —— 不需要 tokio runtime 轮询，不需要任何 Runtime / Handle 装配。facade 自己持有独立线程的 runtime。

    2. 用 axum 包一个 HTTP 服务（主示例）

    推荐的嵌入形态：让 #[tokio::main] 提供异步运行时， 把 facade 的四个操作挂成 HTTP 路由，调用端只需 curl —— 完全绕开手动 block_on。完整可运行版在 arachne/examples/axum_http.rs，下面是核心骨架：

    rust
    use arachne::server::{Arachne, ArachneError, ClusterConfig, WalConfig};
use axum::{routing::{delete, get, post}, Router, extract::Path, http::StatusCode};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // (1) Start an N=1 cluster (single_node): one node per process.
    Arachne::start(ClusterConfig::single_node(1, &dir, WalConfig::default()))?;

    // (2) 轮询到节点自选为 leader（单例免仲裁轮）。
    let deadline = std::time::Instant::now() + std::time::Duration::from_secs(5);
    loop {
        match Arachne::get(b"__ready__").await {
            Ok(_) => break,
            Err(ArachneError::NotLeader { .. } | ArachneError::QuorumUnavailable) => {
                if std::time::Instant::now() >= deadline {
                    panic!("node never became ready within 5s");
                }
                tokio::time::sleep(std::time::Duration::from_millis(10)).await;
            }
            Err(e) => return Err(e.into()),
        }
    }
    println!("node elected leader (facade singleton)");

    // (3) 四个操作挂成 HTTP 路由。
    let app = Router::new()
        .route("/kv/:key/:value", post(handle_put))   // PUT semantics via POST
        .route("/kv/:key", get(handle_get))
        .route("/kv/:key", delete(handle_delete))
        .route("/readyz", get(handle_ready));

    let listener = tokio::net::TcpListener::bind("127.0.0.1:0").await?;
    println!("listening on {}", listener.local_addr()?);
    axum::serve(listener, app).await?;

    Arachne::shutdown()?;
    Ok(())
}

// handler 实现：把 facade 调用与 ArachneError -> 状态码映射放在这里
// （详细版见 arachne/examples/axum_http.rs，含 GET ?stale=1 弱读分派）。
async fn handle_put(Path((key, value)): Path<(String, String)>) -> StatusCode {
    match Arachne::set(key.as_bytes(), value.as_bytes()).await {
        Ok(()) => StatusCode::OK,
        Err(_) => StatusCode::SERVICE_UNAVAILABLE,
    }
}
async fn handle_get(Path(key): Path<String>) -> (StatusCode, String) {
    match Arachne::get(key.as_bytes()).await {
        Ok(Some(v)) => (StatusCode::OK, String::from_utf8_lossy(&v).into_owned()),
        Ok(None) => (StatusCode::NOT_FOUND, "key not found".into()),
        Err(_) => (StatusCode::SERVICE_UNAVAILABLE, "unavailable".into()),
    }
}
async fn handle_delete(Path(key): Path<String>) -> StatusCode {
    match Arachne::delete(key.as_bytes()).await {
        Ok(()) => StatusCode::OK,
        Err(_) => StatusCode::SERVICE_UNAVAILABLE,
    }
}
async fn handle_ready() -> &'static str {
    "ready"
}
    console
    $ cargo run --example axum_http
# 打印: listening on 127.0.0.1:XXXXX
# 另开一个终端（把 XXXXX 换成上面打印的端口）:
$ curl -X PUT 'http://127.0.0.1:XXXXX/kv/hello/world'   # -> ok   (线性写)
$ curl     'http://127.0.0.1:XXXXX/kv/hello'            # -> world (ReadIndex 线性读)
$ curl 'http://127.0.0.1:XXXXX/kv/hello?stale=1'        # -> world (本地读)
$ curl -X DELETE 'http://127.0.0.1:XXXXX/kv/hello'      # -> ok   (线性删)
$ curl     'http://127.0.0.1:XXXXX/readyz'              # -> ready
    i

    纯 CLI / 无 Web 框架场景下，可直接 block_on facade 的 async 方法 （见 arachne/examples/facade.rs，无需自建运行时）。 axum 是 dev-only 依赖，不进入生产依赖树。

    i

    每进程一个节点：第二次 Arachne::start 返回 AlreadyInitialized；start 之前（或 shutdown 之后）的静态读取返回 NotInitialized。多节点集群或成员管理请改用 Runtime / Handle（见 Tutorial）。

    3. 运行示例

    仓库自带的两个完整示例（都可直接运行）：

    console
    $ cargo run --example axum_http   # HTTP 形态（上方 §2），curl 交互
$ cargo run --example facade      # CLI 形态：直接 block_on facade 方法
# facade 输出:
#   get(b"hello")          -> Some(b"world")
#   get_stale(b"hello")    -> Some(b"world")
#   get(b"hello") after del -> None
#   facade lifecycle complete

    示例源码在 arachne/examples/（axum_http.rs 与 facade.rs）；想要更底层的裸装配， 看 arachne/examples/single_node.rs（Tutorial 有讲解）。

    4. 可选：构建并运行参考节点

    不想写任何胶水代码？工作区带了 arachne-node 二进制：它把库与 tonic 传输、 Hyper HTTP/1.1 服务器接在一起，是可运行的真实集群节点，也是嵌入 Arachne 的工作示例。

    console
    $ cargo build --release -p arachne-node
$ arachne-node --config path/to/node.toml

    配置是一个 TOML 文件（字段与 docker/bench/configs/n1.toml 一致）：

    node.toml
    cluster_id = "arachne-bench"
node_id = "n1"
listen = "172.30.0.11:7001"        # raft peer port
data_dir = "/data"
http_listen = "0.0.0.0:8001"        # HTTP client port
initial_cluster = [
  "n1=172.30.0.11:7001",
  "n2=172.30.0.12:7002",
  "n3=172.30.0.13:7003",
]
profile = "lan"                     # "lan" or "wan"
    !

    节点在 initial_cluster 里的自身条目必须等于 listen；配置 schema 目前只接受 IP 字面量。单机体验可以用本机地址写一份 initial_cluster = ["n1=127.0.0.1:7001", …] 的配置。

    curl 接口速览

    节点起来后，KV 读写与运维接口都是纯 HTTP（详见 API Reference 的接口表）：

    console
    $ curl -X PUT 'http://127.0.0.1:8001/kv/hello/world'   # -> ok        (线性写)
$ curl 'http://127.0.0.1:8001/kv/hello'                # -> world     (ReadIndex 线性读)
$ curl 'http://127.0.0.1:8001/kv/hello?stale=1'        # -> world     (本地读)
$ curl -X DELETE 'http://127.0.0.1:8001/kv/hello'      # -> ok        (线性删)
$ curl 'http://127.0.0.1:8001/readyz'                  # -> ready
$ curl 'http://127.0.0.1:8001/metrics'                 # Prometheus 文本格式
    i

    多进程部署下，非 leader 节点的 KV 写/读会返回 409 Conflict，body 带 leader 提示（如 not leader; leader=n1 addr=172.30.0.11:7001）； 503 表示当前无法服务（仲裁不可用 / 超时 / 忙），请求不会挂起。
