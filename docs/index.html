Arachne —— 分布式
可线性化键值引擎

Arachne 是一个基于 raft 共识算法的分布式可线性化键值引擎，以库的形式交付。 把它嵌进你自己的进程，接上存储与传输层，就能获得一个具备 raft 一致性的 Handle 用于读写。 工作区还附带一个接好存储、传输与 HTTP 的参考节点 arachne-node，可直接跑真实集群。

核心是传输无关的

共识、WAL 与 KV 状态机构成 arachne-kv 核心。它只面向 seam 特征编程，核心内没有具体的时钟、 RNG、网络代码或文件 I/O；--no-default-features 时以零外部 crate 编译为精简核心。

一致性语义一瞥

线性化写

put / delete —— 追加到 raft 日志，仲裁持久化后提交，应用于状态机后应答。

线性化读

get —— 默认经 ReadIndex 服务；非 leader 节点会重定向或返回 NotLeader。

本地读

get_stale —— 直接读本地状态机；跨调用不保证单调，仲裁丢失时依然可用。

CP 语义

任何时刻至多一个 leader；失去仲裁时所有线性化操作失败（QuorumUnavailable），绝不降级为多数派读或脑裂。

工作区布局

可嵌入核心

arachne-kv —— src/consensus、src/storage、src/runtime、src/client、src/state_machine、src/profile 与 seam 特征。

叶子 crate

arachne-kv-seam —— seam 特征与共享值类型，自身无任何依赖。

传输实现

arachne-kv-transport-tonic —— tonic / rustls 传输，由 transport-tonic 特性启用。

参考节点

arachne-kv-node —— HTTP 服务器、配置加载、成员管理运维面。

测试支撑

arachne-kv-testsupport、arachne-kv-sim —— 测试与仿真支撑；l2/、l4/、fuzz/、model-check/ 为独立确定性测试框架。
